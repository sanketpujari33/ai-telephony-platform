# 📋 Platform Tasks Catalog: Letters T – Z

Comprehensive specification and tracking for platform capabilities and components categorized alphabetically from T through Z.

---

## 🆃 Letter T
- **`telephony-service`** (`services/telephony-service`): Go 1.22 SIP protocol engine, RTP audio bridging, and carrier trunking.
- **`transcript-service`** (`services/transcript-service`): Speech-to-text post-processing, speaker diarization, and summary generation.
- **`travel-agent`** (`agents/travel-agent`): Flight, hotel, and travel itinerary booking lookups.
- **`@nexora/tools`**: Dynamic agent tool registry and MCP adapter.
- **`@nexora/types`**: Centralized single source of truth for all domain interfaces and contracts.
- **Temporal Workflow Engine**: Durable distributed execution for long-running workflows and scheduled campaigns.

---

## 🆄 Letter U
- **`user-service`** (`services/user-service`): User profiles, workspace tenancy, team member invitations.
- **`user-dashboard`** (`apps/user-dashboard`): Next.js 14 web control portal for tenants.
- **`@nexora/ui`**: React component design system with DataGrids, Schedulers, and Dialpad.

---

## 🆅 Letter V
- **`voice-service`** (`services/voice-service`): Python real-time streaming audio pipeline (Silero VAD, Deepgram STT, Cartesia TTS).
- **HashiCorp Vault**: Zero-secret KV v2 encrypted secrets management (`http://localhost:8200`).

---

## 🆆 Letter W
- **`websocket-service`** (`services/websocket-service`): Real-time WebSocket connection hub for live call waveforms and interim transcripts.
- **`whatsapp-agent`** (`agents/whatsapp-agent`): Meta WhatsApp Business Cloud API rich messaging agent.
- **`workflow-service`** (`services/workflow-service`): Durable agent workflow orchestration via Temporal and LangGraph.

---

## 🆇 Letter X
- **xAI Grok Integration**: LLM inference adapter supporting Grok-2 and Grok-Vision.

---

## 🆈 Letter Y
- **YAML Configuration Loaders**: Docker compose, Kubernetes Helm charts, and CI/CD workflow manifests.

---

## 🆉 Letter Z
- **Zod Schema Validation**: Compile-time and runtime payload validation in `@nexora/config` and API controllers.
